# Exposure to (AI-Generated) Untrustworthy Websites in the 2024 US Election

This repository accompanies the revised manuscript and reproduces the analyses reported in the paper and supplementary materials, using the person-level and daily-level data we are able to share publicly.

## Folder Structure

- `code/` — Analysis script (`analysis.Rmd`) and rendered output (`analysis.pdf`)
- `data/` — Person-level datasets, daily-exposure summaries, and survey data
- `figures/` — Visualizations regenerated by rendering `analysis.Rmd`
- `tables/` — LaTeX table outputs for supplementary materials

## Data Files

| File | Description |
|------|-------------|
| `data/main-2024-person-level.csv` | 2024 participant-level data (N=1,069): exposure flags, visit counts, percentages, demographics, survey weights |
| `data/main-2020-person-level.csv` | 2020 participant-level data for cross-election comparison |
| `data/main-2016-person-level.csv` | 2016 participant-level data for cross-election comparison |
| `data/daily-exposure-2024.rds` | Daily exposure summaries for 2024 (used in temporal event-study analysis) |
| `data/daily-exposure-2020.rds` | Daily exposure summaries for 2020 |
| `data/topic-exposure-2024.rds` | Person × topic × domain-type exposure for 2024 (used in topical composition analysis) |
| `data/verasight_survey/2025-026_client.csv` | Verasight survey responses on perceptions of 2024 untrustworthy website exposure |
| `data/verasight_survey/2025-026_client.rds` | Same survey data in RDS format |

## Data Access

Individual-visit data and NewsGuard's proprietary domain ratings are not included in this repository. Duration, platform referral, and domain-classification sensitivity analyses require those inputs and are stubbed out in `analysis.Rmd`. The person-level files ship all the aggregated variables needed to reproduce every other result in the paper.

## How to Reproduce

Install required R packages:

```r
install.packages(c(
  "tidyverse", "scales", "knitr", "rmarkdown",
  "diagis", "weights", "Hmisc",
  "patchwork", "ggsci", "ggsignif",
  "stargazer", "broom", "car", "kableExtra"
))
```

Then, from the `code/` directory:

```r
rmarkdown::render("analysis.Rmd")
```

This produces `analysis.pdf`, all figures in `../figures/`, and supplementary LaTeX tables in `../tables/`.
